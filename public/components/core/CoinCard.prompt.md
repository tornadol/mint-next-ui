# CoinCard
Storefront product tile — 332×468 with 1px hairline border, no rounding. Coin image is a 200px round photo with a soft drop shadow. Optional badge (`NEW` / `SALE`) sits top-left in brand red.

```jsx
<CoinCard image="/assets/imagery/coins/coin-01.png" meta="L253 • 45mm"
  name="Canada Winning Goal 1 oz 999.9 Fine Silver Proof Coin"
  price="$48" badge="NEW" />
```
